# رقية القرين

تطبيق ويب عربي بسيط يعمل دون اتصال، يعرض مقاطع رقية القرين بترتيبها وتكرارها.

**التطبيق:** https://t1nk333r.github.io/ruqyah-al-qareen/

## المزايا

- عدّاد لكل مقطع مع إعادة لكل مقطع أو للرقية كاملة.
- انتقال بالسحب أو بأزرار السابق والتالي، وانتقال تلقائي بعد اكتمال المقطع.
- حفظ التقدم محليًا على الجهاز دون أي حساب أو إرسال بيانات.
- مظهر فاتح/داكن، حجم نص وتباعد سطور قابلان للضبط، واهتزاز اختياري (٤٥ مللي ثانية).
- يعمل دون اتصال ويمكن تثبيته على الشاشة الرئيسية.
