# رقية القرين

تطبيق ويب عربي بسيط يعمل دون اتصال، يعرض مقاطع رقية القرين بترتيبها وتكرارها.

**التطبيق:** https://t1nk333r.github.io/ruqyah-al-qareen/

## المزايا

- تبويب لكل سورة، عليه علامة ✓ إذا اكتملت السورة اليوم، مع تقدم السورة المعروضة وتقدم رقية اليوم كاملة.
- روابط مباشرة لكل سورة: `#qaf` و`#jinn` و`#takwir` و`#kafirun` و`#nas`. بلا رابط يفتح التطبيق دائمًا على سورة ق عند أول مقطع لم يكتمل.
- عدّاد لكل بطاقة مع إعادة لكل بطاقة على حدة.
- زر الإعادة يفتح ثلاثة نطاقات: تقدم اليوم، أو سجل آخر سبعة أيام، أو كل شيء؛ مع تأكيد قبل الحذف.
- انتقال بالسحب أو بأزرار السابق والتالي داخل السورة؛ لا يُتاح «التالي» حتى تكتمل تكرارات المقطع، ثم ينتقل التطبيق تلقائيًا.
- عند اكتمال سورة تظهر رسالة فيها زر للانتقال إلى السورة التالية التي لم تكتمل.
- حجم النص يُضبط تلقائيًا لتظهر الصفحة كاملة دون تمرير.
- تتبّع يومي: تُعاد العدادات بعد منتصف الليل، ويُسجَّل اليوم عند اكتمال جميع المقاطع.
- سجل الأيام في الإعدادات يعرض آخر ثلاثين يومًا، ومعها السور التي اكتملت في الأيام التي لم تكتمل فيها الرقية كلها، دون أي عبارات لوم أو سلاسل تنافسية.
- حفظ التقدم محليًا على الجهاز دون أي حساب؛ لا يُرسل شيء عن القراءة أو التقدم أو السجل أو الموقع.
- عدّ مجهول لمرات فتح التطبيق على خادم المطوّر الخاص، ويُفصَّل في الإعدادات: يُستعمل عنوان IP ومعرّف المتصفح مؤقتًا للعدّ فقط، ثم تُحفظ أرقام إجمالية (المتصفح والنظام وعرض الشاشة والبلد)، دون ملفات تعريف الارتباط. يُعطَّل العدّ بضبط المفتاح `skipgc` على القيمة `t` في `localStorage`.
- مظهر فاتح/داكن، حجم نص وتباعد سطور قابلان للضبط، واهتزاز اختياري (٤٥ مللي ثانية).
- يعمل دون اتصال ويمكن تثبيته على الشاشة الرئيسية، مع خطوات التثبيت على آيفون وآيباد.
